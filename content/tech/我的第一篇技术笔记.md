# 我的第一篇技术笔记

## 一、问题背景

我开始从零搭建个人知识网站，希望以后只需要在 Obsidian 中写内容，网站可以自动生成和发布。

## 二、当前方案

我采用的方案是：

- Obsidian 写作
- Markdown 管理内容
- Quartz 生成静态网站
- GitHub Pages 部署
- 自定义域名作为个人知识入口

## 三、阶段成果

目前已经完成：

1. 安装 Node、npm、Git。
2. 下载并初始化 Quartz。
3. 本地运行 Quartz 网站。
4. 建立基础栏目。
5. 创建自动文章列表脚本。

## 四、复盘总结

个人知识网站的核心不是页面设计，而是建立一个长期稳定的内容输入系统。
