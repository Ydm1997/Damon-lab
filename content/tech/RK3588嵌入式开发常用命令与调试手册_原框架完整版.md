## 时间同步

### 时间同步-系统时间-pps

```c
//1.思路
    //1.1.设备首先通过PPS信号接收到一个精确的秒脉冲。在接收到PPS信号后，设备将内部系统时间的毫秒及以下部分清零，并开始重新计算毫秒时间。
    //1.2.紧接着，设备通过串口接收到GPRMC报文。报文中包含了准确的UTC时间信息。
    //1.3.设备将接收到PPS信号到解析出GPRMC中UTC时间所用的时间（通常在毫秒级别）与UTC整秒时间相加，得到准确的系统时间。至此，一次时间同步过程完成。每秒都会进行这样的过程，以确保系统时间的准确性
//2.影响因素
	//系统调用延迟：gettimeofday是一个系统调用，它本身有一定的执行时间，所以采用clock_gettime()实现纳秒级的处理。
//3.代码
//当中断来的时候，执行以下：
static void PpsInterruptHandle(char *bufIn)
{
    if (strncmp(bufIn, "1", 1) != 0)  // 仅当接收到有效的PPS信号时才处理
    {
        printf("Invalid PPS signal.\n");
        return;
    }
	//获得系统实施时间
    struct timespec local_time;
    if (clock_gettime(CLOCK_REALTIME, &local_time) < 0) {
        perror("clock_gettime");
        return;
    }
	//清除中断时刻开始的毫秒及毫秒以下时间
    ClearSystemTimeMilliseconds(local_time);
	//获取gprmc报文的utc时间
    if (!GetUtcFromGprmc()) {
        return;
    }
	//同步系统时间，将UTC的整数秒 + 中断开始到收到解析报文的延迟时间（毫秒及以下）
    struct timespec precise_time = CalculatePreciseTime();
    SyncSystemTime(precise_time);
}
```

## vsftpd

### 1.下载

```shell
sudo apt update
sudo apt install vsftpd -y
```

### 2.创建用户

```shell
#下列命令输入后，按提示输入密码：ftpuser
sudo adduser ftpuser

#创建userlist文件
sudo touch/vim /etc/vsftpd.user_list

#追加
ftpuser

#给ftpuser权限
sudo chown ftpuser:ftpuser /mnt/mmc/mmcblk0
sudo chown -R root:ftpuser /mnt/mmc/mmcblk0

sudo chmod 755 /mnt/mmc/mmcblk0
```

### 3.修改配置文件

```shell
#修改 /etc/vsftpd.conf

#禁止匿名访问
anonymous_enable=NO

#允许本地用户
local_enable=YES
write_enable=YES

#设置umask
local_umask=022

#限制用户只能访问自己的目录
chroot_local_user=YES
allow_writeable_chroot=YES

#指定FTP根目录
local_root=/app/slamdata/resources

#启用用户列表，只允许列表中的用户
userlist_enable=YES
userlist_file=/etc/vsftpd.user_list
userlist_deny=NO
```

### 4.重启

```shell
sudo systemctl restart vsftpd
```
